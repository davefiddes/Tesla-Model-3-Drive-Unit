# Tesla Oil Pump LIN

## Getting started

1. Connect the Saleae Logic analyzer to the RX pin on the low-voltage side of a LIN bus transceiver on the same bus as the Tesla oil pump
2. Capture the traffic you wish to analyze
3. Go to the Extensions tab in Logic 2 and select "Load Existing Extension..." from the hamburger menu
4. Pick the `extension.json` file in this directory
5. Go to the Analyzers tab and a LIN alayzer and connect to the correct pin
6. Add the Tesla Oil Pump LIN analyzer and connect to the LIN analyzer
7. See what the device is doing
